# 复盘自己 · 每日记录（体验版）

一款以「发现式复盘」为核心的引导式个人复盘工具 —— 每天 5 分钟，跟着书中的八栏结构如实记录，写完立刻看见自己。

> 方法论来自《复盘自己：从记录到蜕变的行动指南》[日]山田智惠。
> **复盘不是反思错误，而是发现自己早已拥有的财富。**

## 在线体验

打开即用，无需安装、无需登录：

- https://miapersist.github.io/self_review_public/

## 功能

- **八栏引导填写**：事件 → 想法和感受 → 行动 → 结果；重新注意到了什么 → 从现在开始可以采取的行动 → 可能的结果；对自己的新发现
- **切分实时提示**：帮助你把「客观事实」与「感受判断」分开，把「依赖他人的期待」转成「自己能做到的行动」
- **情绪轮盘**：普鲁奇克 8 主情绪 × 3 强度，点选即插入
- **一天多条**：不限条数，想记几条记几条
- **月历 / 清单双视图**：回看历史
- **即时正反馈**：保存后给你一句取自你文字的发现，绝不编造
- **明暗主题**、**数据导出/导入**、**每周日全量自动备份**、**GitHub 云同步**

## 隐私说明

- **无账号、无服务器**：所有记录默认只保存在你自己的浏览器（localStorage）
- 数据不上传、不共享，代码里不含任何第三方统计
- 如需多设备同步或备份，可在「我的」页自行配置 GitHub 云同步（使用你自己的 GitHub 账号，数据只进你自己的仓库）
- 清浏览器缓存会丢失数据，建议开启每周自动备份或云同步

## 技术

- 单文件 HTML（HTML + CSS + JS 全内联），零依赖、零构建
- 数据存储：浏览器 localStorage（多层 key）+ 可选 GitHub Contents API 云同步
- 双击即可在本地使用，也可托管于任意静态站点

## 开源

本仓库仅包含可公开体验的 MVP 内容，不含任何个人数据。
